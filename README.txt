NOVA AI V1.0 — ZERO-BUDGET STARTER

Files:
- index.html: app interface and working features
- manifest.json: installable web app metadata
- sw.js: offline cache

WORKING FEATURES:
- Home dashboard
- Planner: add, complete and delete tasks
- Finance: record income and expenses
- Trading risk/reward calculator
- Basic built-in assistant responses
- Local data storage and JSON export

IMPORTANT:
- This is an offline-first starter app, not yet a generative AI assistant.
- No live stock exchange feed, broker connection, auto-trading, cloud sync or login.
- Data stays in this browser/device. Export a backup before clearing browser data.
- Trading calculations are estimates and exclude charges, slippage and lot constraints.

MOBILE INSTALL:
1. Upload these files to a GitHub repository.
2. In repository Settings > Pages, deploy from main branch / root.
3. Open the published HTTPS Pages address in Chrome on Android.
4. Chrome menu > Add to Home screen / Install app.
5. Open NOVA from your home screen.

All source files can be edited on Android using a code editor such as Acode.
